# MVP Scope

## MVP Goal

Build a working local app where a user can enter a rough goal, generate a detailed todo breakdown, edit it, and save it as a project.

## Must Have

- Goal input
- AI breakdown button
- Structured task output
- Editable todo list
- Check/uncheck tasks
- Add task
- Delete task
- Save project to SQLite
- Open saved project
- Basic API key configuration

## Should Have

- Task reorder
- Task detail notes
- Task completion criteria
- Regenerate all tasks
- Regenerate a selected task into subtasks
- Basic provider/model selection

## Could Have Later

- Login
- Encrypted backend API key storage
- Workspace separation
- Import/export
- Markdown export
- Calendar or timeline view
- Dependency graph
- Per-user SQLite database
- Hosted SaaS mode

## MVP Quality Bar

The generated list should feel immediately actionable. If the user must manually rewrite most tasks before starting, the MVP has not succeeded.
